# 独立系统开发版使用与验收

更新：2026-09-08。本轮实现知识独立管理，以及 Admin 受限协议模型接入开发版。不是完整生产/长期规划验收。

## 本轮实现

- knowledge 自有 Web、管理员初始化、独立 Cookie 会话、Origin/CSRF、管理 API；不调用 Admin。管理操作沿用知识业务函数，审计主体来自本地会话，不接受浏览器伪造 actor。
- 知识来源可明确拒绝，未发布草稿与待处理任务被阻断，正文保留审计；拒绝操作不会删除资料。主要管理列表支持 offset/limit，页面按 200 条翻页，不将本页数量当全库数量。
- 发布 Worker 在批次前后与落库前核对索引指纹，不匹配即 INDEX_CONFIG_MISMATCH，保留旧发布指针；恢复一致配置后可手动重试。查询向量与候选索引不匹配时明确降级/覆盖警告。
- Admin 移除知识页面与代理；旧 /api/admin/v1/knowledge/* 对已登录管理员返回 410 KNOWLEDGE_MOVED，提示进入知识管理。
- Admin 自有供应商配置、Fernet 加密上游 Key、模型别名路由、用户模型 Key（仅存哈希）、有效期/撤销/模型范围/RPM。
- Admin /v1/models 与 /v1/chat/completions 实际适配兼容 Chat Completions 的第三方 API，普通 JSON 和 SSE；上游错误脱敏、不跟随重定向、不自动重试。
- 持久调用元数据：调用者、渠道、模型、耗时、HTTP 状态、成功/失败/取消、Token 用量；缺失为 null。UI 按当前页最多 100 条显示统计，不伪装全站汇总。
- 两套 Compose 不再需要共享外部网络；knowledge Dockerfile 构建自身 Web。旧 LiteLLM models profile 仅保留为可选实验模板，与当前 Admin 内置转发配置不互通。

## 升级原则

先备份已有数据库，停止对应旧进程后执行迁移，再启动新版本。不要覆盖 .env，不复用 Admin 密码到知识系统，不删除旧数据库。本轮只在临时数据库验证迁移，没有对用户业务数据库执行升级。

### 知识服务

```powershell
cd E:\Opsark\Opsark_knowledge
.\.venv\Scripts\python -m pip install -c constraints.txt -e ".[test]"
.\.venv\Scripts\python -m alembic upgrade head
.\.venv\Scripts\python -m knowledge.bootstrap
cd web
npm ci
npm run build
cd ..
.\.venv\Scripts\python -m uvicorn knowledge.main:app --host 127.0.0.1 --port 8002 --workers 1
```

bootstrap 仅首次创建本知识系统管理员时运行，密码至少 12 字符，不写到文档。另开终端在知识根目录运行：

```powershell
.\.venv\Scripts\python -m knowledge.processing
```

浏览器 http://127.0.0.1:8002。知识管理不需要 KNOWLEDGE_SERVICE_TOKEN；该变量仅保留给可选 /internal/v1 服务集成，空值拒绝内部 Token 接口但不影响本地登录。core 仍填写 http://127.0.0.1:8002/api/v1 和知识页面签发的知识 Key。

开发热更新在 knowledge/web 执行 npm run dev，端口 5175，仍需启动知识 API。

### Admin 模型平台

```powershell
cd E:\Opsark\Opsark_admin
.\.venv\Scripts\python -m pip install -c constraints.txt -e ".[test]"
.\.venv\Scripts\python -m alembic upgrade head
```

已有 Admin 账号继续使用；只有首次安装才运行 python -m app.bootstrap。在本地自行生成上游密钥加密主密钥：

```powershell
.\.venv\Scripts\python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

在 Admin .env 设置：

```dotenv
MODEL_KEY_ENCRYPTION_KEY=替换为本地生成值
MODEL_ALLOWED_HOSTS=provider-a.example,provider-b.example
```

主机占位符必须换成真实供应商的精确域名，不包含协议、端口、路径或通配符。空白名单禁止配置/调用任意上游；仅支持 HTTPS/443。主密钥独立安全备份，不能随意更换，否则旧上游 Key 无法解密；轮换需单独设计重加密流程。

```powershell
cd web
npm ci
npm run build
cd ..
.\.venv\Scripts\python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --workers 1
```

浏览器 http://127.0.0.1:8001，依次：供应商 API → 模型路由 → 用户模型 Key → 调用监控。连接测试只执行上游 GET /models，不证明生成/流式/参数兼容。

core 模型 base URL 改为 http://127.0.0.1:8001/v1，Key 使用本平台签发的 omk_ Key；不是供应商 Key、知识 Key、管理员密码或 LiteLLM 模板 Key。旧 .env 的 MODEL_BASE_URL/MODEL_CONSOLE_URL/KNOWLEDGE_* 不控制新转发路由；渠道以数据库中配置为准。

## 精确接口

| 服务 | 已实现接口 |
| --- | --- |
| knowledge 管理登录 | /api/admin/v1/session：POST、GET、DELETE；独立 opsark_knowledge_session Cookie |
| knowledge 本地管理 | /api/admin/v1/knowledge/*：原知识管理资源，使用本地会话/CSRF |
| Admin 供应商 | /api/admin/v1/providers：GET、POST；/{id} PUT；/{id}/test POST |
| Admin 路由 | /api/admin/v1/routes：GET、POST；/{id} PUT；别名不允许原位改名 |
| Admin 模型 Key | /api/admin/v1/model-keys：GET、POST；/{id} DELETE 撤销 |
| Admin 调用记录 | /api/admin/v1/calls?offset=0：GET，单页 100 条 |
| 模型公共接口 | GET /v1/models、POST /v1/chat/completions，Bearer omk_ Key |

Admin 不再要求运行知识服务，知识不再要求 Admin 在线。管理 Cookie/Key/数据库各自独立。

## 开发版边界与待验收

- 首版是兼容协议的受限适配器，不是任意供应商协议转换器。不支持非兼容原生协议、多模态完整验收、复杂路由、自动跨渠道重试或财务计费。
- thinking/response_format/stream_options 等参数按已允许字段传递，供应商是否支持须真实验证；不自动注入流式 usage 选项，未返回用量显示未知。
- 单 API 进程，RPM 为进程内窗口，转发最多 8 个并发；不能多进程部署后宣称共享额度。撤销阻止新请求，不强制中断已经开始的调用。
- SSE 支持兼容接口常见的逐行 data JSON 和 [DONE]；流结束缺少 DONE 标失败。输出后的错误通过 SSE error 表达，不重试。测试包含正常流/不完整流，真实客户端断开和所有供应商 SSE 差异仍需验收。
- 日志仅覆盖进入转发流程的请求，不包含全部鉴权失败流量。进程崩溃可能留下 running，UI 明确说明；自动对账/异常任务恢复、聚合图表、日志保留和审计完善待开发。
- 主机白名单由服务器运营者控制，需可信供应商域名。生产还应限制出站网络/私有网段、验证 DNS/代理策略与供应商条款，不能将应用白名单视为完整网络隔离。
- 知识资料所有者/空间隔离、多来源关联、适用版本、独立索引构建代次、生产检索和长期记忆尚未完成；本轮索引指纹检查是先行防护，不是完整重建系统。
- 没有调用真实模型供应商，没有改用户 .env/上游凭据，没有验证 Docker/PostgreSQL 或生产备份恢复。

## 验证方式

本轮结果：Admin 14 项、知识 16 项 pytest 通过；两项目 Ruff F 检查和 Web 构建通过；真实独立进程/Edge 浏览器烟测通过；core 上传契约烟测通过。知识状态查询额外验证同安装标识的不同库 Key 不能越权。没有真实供应商或用户数据库操作。依赖工具存在弃用提示，不影响本轮测试结果。

两项目各运行 python -m pytest -q、ruff check --select F；各 web 运行 npm run build。新增迁移测试验证旧表内容保留及重复 upgrade。

Admin 的模型测试使用 httpx.MockTransport，验证两家模拟渠道切换、上游/用户 Key 隔离、加密存储、JSON/SSE、错误脱敏、过期/撤销/限流、停用、白名单及地址更换重输 Key。

平台根目录可执行 node scripts/smoke-independent.mjs：用各项目 .venv、新临时 SQLite、随机测试管理员和 Edge 无头浏览器，先在没有 Admin 的情况下操作知识，再停掉知识测试 Admin 配置。不会访问收费上游；临时合成数据库和截图保留在脚本打印的系统临时目录，测试进程结束后关闭。
