## 复现

各项目根目录运行 `.venv/Scripts/python -m pytest -q`。平台 `web` 目录运行 `npm ci` 和 `npm run build`。

两个项目分别安装好虚拟环境后，从平台根目录运行：

```powershell
.venv/Scripts/python scripts/smoke_services.py
```

如已安装 Microsoft Edge，可追加 `--browser` 运行界面测试；脚本使用 web 的 Playwright 开发依赖。浏览器截图位于 `web/test-results/knowledge-documents.png`，已视觉检查，属于忽略提交的测试产物。
