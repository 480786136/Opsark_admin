# 调用详情与提炼排障

## 升级

停止 Admin API、Knowledge API 和 Worker。在两个项目目录中分别执行：

```bash
.venv/bin/python -m alembic upgrade head
```

然后重启三个进程。此次 Admin 新增 `0003` 调用详情表；Knowledge 使用 `knowledge_0003` 前后对照表。前端构建已更新；若在另一台设备部署，在各自 `web` 目录执行 `npm run build`。

## Admin 调用监控

点击「查看输入 / 输出详情」，或输入 Knowledge 显示的 Admin 请求 ID 查询。
详情包含输入、输出、HTTP 状态、耗时、结束原因、输入/输出 Token。
流式调用展示合并后的文本、推理文本和工具参数，不是逐帧回放。
分类统计只针对当前页（最多 100 条），支持按模型、调用方、供应商、状态分组。
已知 Token 求和与未知条数分别显示；不是全量报表，也不是计费账本。

`succeeded` 表示网关请求完成，不保证业务结果有效。`finish_reason=length` 表示输出达到限制，可能不是完整 JSON；Knowledge 会拒绝不完整结果，保留原草稿。
不能仅凭输出恰好是 5000 Token 就确定历史失败原因，旧调用没有正文或结束原因快照，无法追溯恢复。

Admin `.env` 可选设置（重启生效）：

```dotenv
MODEL_CALL_CAPTURE_ENABLED=true
MODEL_CALL_RETENTION_DAYS=7
```

新调用默认采集。请求头、认证 Cookie 不采集；已知上下游 Key、常见凭据字段和文本模式会过滤，再使用现有 `MODEL_KEY_ENCRYPTION_KEY` 加密保存。
自动过滤不能保证覆盖所有业务敏感信息；正文仍属于敏感运维数据，仅管理员可查看，禁止对外分享。
每侧最多保存 64 KiB 展示文本，超限有明确标记。JSON 错误响应也会过滤保存；非 JSON HTTP 错误页不采集。
保留期限定 1–90 天，过期详情在完成新调用或读取详情时清理；无访问时不会后台定时物理删除，但读取时不会返回过期内容。备份生命周期须另行管理。
关闭采集只影响新调用，已保存快照到期清理。历史正文无法补回。
快照保存失败不会中断模型调用，Admin 服务日志记录 `call_detail_save_failed`、请求 ID 和异常类型。

## Knowledge 开发者日志

失败会写入 Worker 标准错误输出及 `Opsark_knowledge/data/worker.log`（从项目目录启动时）。
单文件上限 5 MiB，最多保留 3 个轮转备份；适用于当前单 Worker 部署，多进程部署应由进程管理器集中收集标准错误输出。
可通过 Knowledge `.env` 的 `WORKER_LOG_PATH` 指定其他路径，空字符串关闭文件日志。

每条 JSON 日志包含时间、任务 ID、文档 ID、修订、处理阶段、错误码、异常类型、栈文件/行号。
已收到模型响应时还包含 Admin 请求 ID、HTTP 状态、结束原因、Token 用量。
不记录原始异常消息、SQL 参数、模型正文、源资料或 Key；查看正文请使用 Admin 受权限保护的详情。

常见错误：

- `AI_INCOMPLETE_OUTPUT`：输出未正常结束，检查结束原因和输出预算。
- `AI_SCHEMA_INVALID` / `AI_RESPONSE_INVALID`：JSON 结构不符合约定。
- `AI_INVALID_REFERENCE`：证据引用不合法。
- `AI_TIMEOUT` / `AI_HTTP_ERROR` / `AI_CONNECTION_ERROR`：模型服务请求失败。
- `AI_DATABASE_ERROR`：检查迁移、数据库连接和日志栈位置。
- `AI_SENSITIVE_CONTENT`：输入或输出触发敏感信息校验。

修复后在文档页点击「AI 重新提炼」。旧失败任务不会自动补全日志，也不会自动再次产生模型费用。

## 供应商与路由高级参数

Admin 的供应商编辑页可配置默认高级参数；模型路由编辑页可配置强制参数。只支持经过类型和范围校验的参数，不接受任意 JSON。

合并优先级为：供应商默认值 `<` 调用请求 `<` 路由强制参数。供应商默认值适合统一设置渠道习惯；路由强制参数适合 Knowledge 等固定用途，避免调用方误覆盖。

DeepSeek 经验提炼建议在对应供应商设置“思考模式：关闭”。如果同一供应商还有需要思考的用途，应建立单独的 Knowledge 模型路由，并只在该路由强制关闭思考。保存后无需重启，新请求立即使用新参数。

当前白名单包括思考模式、推理强度、Temperature、Top P、最大输出 Token、Presence penalty 和 Frequency penalty。关闭思考时不能同时设置非 `none` 的推理强度；`max_tokens` 和 `max_completion_tokens` 不能同时存在。
