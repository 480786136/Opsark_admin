## 一期之后

| 功能 | 归属 | 前置约束 |
| --- | --- | --- |
| 公众注册、用户中心、设备登录 | Admin | 不影响知识独立管理，外部主体通过标识映射 |
| 充值、账本、退款、对账 | Admin | 用量监控不是账本，缺失 usage 不等于零 |
| 订阅、套餐、完整团队角色 | Admin；知识持有资源权限 | 基本多用户隔离需提前完成 |
| 复杂模型路由与熔断 | Admin | 明确重试边界，防止重复生成/费用 |
| 用户/项目/服务器记忆 | 独立领域，部署归属待设计 | 同意、所有者、证据、范围、有效期、冲突、更正、删除 |
| AI 经验提取 | Knowledge | 只生成草稿，记录模型/规则来源，不自动批准 |
| 多来源自动合并与知识去重 | Knowledge | 先有来源关联和版本归属；上传幂等不是语义去重 |
| PDF/Word/OCR、网页/Git | Knowledge | 来源授权、解析隔离、对象存储、敏感内容与注入防护 |
| 同步与删除传播 | 各领域 | 缓存、索引、日志、备份各自保留规则 |
| 可选统一身份 | 两系统 | 不强制共用 DB、会话或高权限 Token |
| 多副本、共享限流/队列 | 各服务 | 容量/可用性需求触发，不提前堆设施 |

知识回答通用问题；记忆记录特定用户/项目的偏好和约定；任务状态由 core 管执行进度。不能自动把任务转用户画像或公共知识，不能把历史环境当服务器当前事实。
