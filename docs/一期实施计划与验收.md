## 验收方法

两个项目各执行自己的 python -m pytest -q；平台 web 执行 npm ci 和 npm run build。独立进程烟测应验证管理端登录→远程建库/签发 Key→知识公共上传→Worker→发布→检索；临时测试数据库不能使用真实运维资料。

关键断言：模型 Key/知识 Key/服务 Token 不混用；客户端不能访问内部 API；同上传重复提交只生成一份记录；编辑冲突返回 409；索引失败不损失旧发布内容；知识离线不阻断平台登录；下架和删除后引用不再可访问。
